## 1. 發布前阻斷門檻（P0）

- [ ] 工作樹乾淨，變更已提交至 `main`，並確認沒有把 `.env`、service-role key、Access Token 或私鑰帶入提交。
- [ ] CI 成功，包含 Node／TypeScript／欄位契約／安全稽核與 secrets scan。
- [ ] CodeQL 最新分析成功，現行開放告警為 0；新告警必須完成修正或逐筆研判。
- [ ] 若有 SQL 變更，Migration workflow 成功，並確認 migration 可重複執行且沒有刪除／截斷正式資料。
- [ ] 若有 Edge Function 變更，Edge functions deployment 成功，且必要的環境變數／Secret 已在 Supabase 設定。
- [ ] RLS、RBAC、Storage private policy 與帳號密碼政策均已套用；未使用匿名權限繞過業務權限。
- [ ] 回滾 commit、資料庫 migration 回復策略與負責人已記錄。

## 2. V2 登入與角色權限

- [ ] 登入、登出、Session 過期與重新登入正常。
- [ ] 一般使用者只能看到被授權的系統與資料。
- [ ] 課室主管可處理所屬單位的核可工作，不可跨單位越權。
- [ ] 派車管理員可接續核可後的派車流程；駕駛只可處理指派給自己的案件。
- [ ] 後台管理員可檢視資安告警、稽核紀錄與必要系統設定。
- [ ] 未授權路由會導回 V2 登入頁，且不在畫面暴露資料庫錯誤或 Stack trace。

## 3. 核心業務流程

- [ ] 報修：建立 → 派工 → 接單 → 維修 → 驗收 → 結案，資料與狀態歷程完整。
- [ ] 派車：一般使用者申請 → 單位主管核可 → 派車管理員派車 → 駕駛接單／回報 → 完成與結案。
- [ ] 帳號申請：申請 → 主管審核 → 建立帳號 → 首次登入／密碼政策驗證。
- [ ] 巡檢：巡檢點載入、簽到、異常回報、附件與稽核事件均正常。
- [ ] 電子交接簿：建立、接班確認、附件、通知與歷程查詢正常。
- [ ] 失敗、重複送出、逾時與權限不足情境均顯示繁體中文且不重複寫入。

## 4. 圖臺與視覺冒煙測試

- [ ] V2 平面圖可載入樓層、圖面與標記；未登入無法取得 private `floorplans`。
- [ ] V2 3D 圖臺可載入 7 層模型、貼圖、樓層切換與標記。
- [ ] 桌面寬度與手機寬度均檢查導覽列、表格、篩選列、Modal 與操作按鈕。
- [ ] 頁首共用品牌列、使用者、連線狀態、Asia/Taipei 時鐘順序一致。
- [ ] Light theme 文字對比與錯誤／警告／成功色彩可讀，沒有深色背景上的深色文字。

## 5. 資料、檔案與安全驗證

- [ ] 重要資料讀取／寫入符合 RLS 與角色範圍，不能只依前端隱藏按鈕保護。
- [ ] `floorplans`、`repair-files`、`handover-attachments`、`vehicle-dispatch-files` 的 bucket／MIME／大小／路徑限制正常。
- [ ] Signed URL 有效期限、過期後拒絕與匿名存取拒絕均已驗證。
- [ ] 直接 REST／Storage／Auth／Edge Function 的 401／403／429／5xx 會進平台日誌與必要告警。
- [ ] `security_alerts`、操作稽核、LINE 投遞歷程與告警去重均可查詢。
- [ ] 前端錯誤回報已遮蔽 Token、密碼、Cookie、Authorization 與個資。

## 6. 自動化部署與上線後驗證

- [ ] Hardened Pages deployment 的 build、deploy、verify-deployment 全部成功。
- [ ] 變更 Edge Function 時，確認 Edge functions deployment 成功。
- [ ] 加上版本查詢參數重新開啟 V2 登入頁、後台、核心模組，確認不是 CDN 舊快取。
- [ ] 低頻 synthetic probe 回報 `state: healthy`；GitHub Pages、REST、Storage 狀態碼與延遲符合預期。
- [ ] Supabase platform log monitor 最近一次為 `healthy`，且 Logs Explorer 六組查詢仍可用。
- [ ] 上線後 30 分鐘檢查資安告警、錯誤門檻、LINE 與 GitHub Actions，沒有新 P0／P1 異常。
