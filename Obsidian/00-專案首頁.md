## 目前狀態

- V1 為靜態多頁網站；V2 使用 Next.js 建置後輸出靜態網站。
- GitHub 負責版控、建置及檢查；地端 IIS／WSL 需要各自部署及驗收。
- 使用 Supabase Auth、PostgreSQL、Storage 與 Edge Functions。
- 主要功能包含巡檢、報修、派工、維修、設備、圖資與電子交接。
