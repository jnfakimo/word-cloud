# 主機上線檢查紀錄（2026-09-06）

## 範圍與結論

本次檢查本機 IIS 兩個已啟動站台、WSL 正式 Supabase、Docker Desktop 開發環境，以及本專案的發布檢查。**目前仍未完成正式上線驗收，也不代表通過 ISO/IEC 27001 認證。**

## 已完成

- 正式站 126 個 HTML 頁面與直接引用資源合計 179 個 URL，修正後均回傳 HTTP 200。這是 HTTP 可用性檢查，不等同登入後功能驗收；動態載入的資源與全部業務操作尚未涵蓋。
- 舊站匿名存取的工作處理序權限已修正，入口由權限錯誤恢復 HTTP 200。
- IIS 增加 SAMEORIGIN 防嵌入設定、移除伺服器識別標頭，並設定自訂錯誤模式。IIS 設定與原 web.config 均已備份。
- 本機舊資料表與舊 RPC 權限已收斂；未刪除資料，未重設任何密碼。詳細識別與測試結果保存在本機受控維護紀錄，不在公開 repository 列出。
- 本機 public schema 76 張資料表均啟用 RLS；這不代表每個政策與角色隔離都已完成驗證。
- 建立本機 PostgreSQL 自訂格式備份與 Storage 檔案備份，目錄限 root 存取；備份目錄清單、壓縮檔清單及 SHA-256 驗證成功。尚未完成完整還原演練，備份與資料同主機，不視為異地備份。
- 修正商用就緒檢查：25 個舊轉址頁補上 CSP；GridStack 資源補上 SRI；新視窗連結補 noopener；V2 連結改對實際匯出目錄驗證，目錄須有 index.html。已整合最新發布稽核：CI 建置 V2 並產生不發布的稽核產物，再檢查實際 HTML／CSS。
- 本機 V2 build、正式打包（126 頁）、商用就緒檢查（124 應用 HTML，0 error／0 warning）、6 項稽核器回歸測試、正式相依套件 audit（0 vulnerability）均通過。
- 資安設計檢查 0 error／2 warning，仍須人工檢視 HTML 注入與列印文件輸出。
